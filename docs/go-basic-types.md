# Go の基本的な型 — ここまでのまとめ

対象：**論理値型（bool）／数値型／文字列型（string）**

Go 共通のルール：
- どの型にも **ゼロ値**（初期化しなかったときの値）がある。`nil` にはならない。
- 型が違う値どうしはそのまま混ぜられない。**変換は明示的に書く**（`int64(i)` など）。
- `var x T` は宣言だけ（ゼロ値）、`x := 値` は宣言と代入を同時（型は右辺から推論）。

---

## 1. 論理値型 bool

| 項目 | 内容 |
|------|------|
| 型名 | `bool` |
| 値 | `true` / `false` の 2 つだけ |
| ゼロ値 | `false` |
| 演算子 | `&&`（かつ）, `\|\|`（または）, `!`（否定） |
| 生成元 | 比較演算（`==` `!=` `<` `<=` `>` `>=`）の結果も bool |

**C との違い**：数値を条件式に入れられない。`0 == false` のような扱いはしない。

```go
n := 3
if n {          // ← コンパイルエラー：bool ではない
if n != 0 {     // ← こう書く
```

## 2. 数値型

### 整数

| 分類 | 型 | 備考 |
|------|----|------|
| 符号あり | `int8` `int16` `int32` `int64` | ビット数が名前どおり固定 |
| 符号なし | `uint8` `uint16` `uint32` `uint64` `uintptr` | 負の数を持てない |
| 環境依存 | `int` `uint` | 実行環境で 32 or 64 bit（今どきは 64）。**普通はこれを使う** |
| 別名 | `byte` = `uint8` / `rune` = `int32` | byte はバイト、rune は Unicode コードポイント |

- ゼロ値：`0`
- 割り算 `/` は整数どうしなら小数を切り捨て（`7 / 2 == 3`）。余りは `%`。
- 桁あふれしても panic せず、ぐるっと回る（wrap around）。

### 浮動小数点・複素数

| 型 | 備考 |
|----|------|
| `float32` `float64` | IEEE 754。小数リテラル（`3.14`）の既定は `float64` |
| `complex64` `complex128` | 複素数。練習では基本使わない |

- ゼロ値：`0`

### 型変換は必ず明示

```go
i := 12345          // int
var i64 int64 = int64(i)   // int → int64 は自分で書く（cmd/pra01 でやった）
f := float64(i) / 2        // 整数と float を混ぜるときも変換が要る
```

異なる型のまま `+` などをするとコンパイルエラー。
（例外：`const` の「型なし定数」は文脈に合わせて自動で馴染む。`const x = 10` など）

## 3. 文字列型 string

| 項目 | 内容 |
|------|------|
| 型名 | `string` |
| 中身 | **バイト列**（普通は UTF-8 でエンコードされた文字）。**変更不可（immutable）** |
| ゼロ値 | `""`（空文字列。`nil` ではない） |
| 連結 | `+` |
| 比較 | `==` `!=`、`<` などは辞書順（バイト単位） |

### リテラルの 2 種類

```go
a := "行1\n行2"      // "..." 解釈あり：\n は改行になる
b := `C:\tmp\new`     // `...` そのまま：\t や \n も文字どおり。複数行も書ける
```

### 長さとインデックス（要注意）

```go
s := "あいう"
len(s)      // 9 ← 文字数ではなく「バイト数」（1文字3バイト）
s[0]        // byte（uint8）が返る。1文字ぶんではない
```

**文字単位で回したいときは `range`**：

```go
for i, r := range s {   // i = バイト位置, r = rune（1文字）
    fmt.Printf("%d: %c\n", i, r)
}
```

### 変換

```go
[]byte(s)          // バイトのスライスへ
[]rune(s)          // 文字（rune）のスライスへ
string([]byte{...})
string([]rune{...})
string(rune(65))   // "A"（コードポイント → 文字）
```

### 数値 ⇄ 文字列

`s[0]` のような添字ではできない。パッケージを使う：

```go
import "strconv"
strconv.Itoa(123)        // int → "123"
strconv.Atoi("123")      // "123" → int, error（多値！②の仕組み）
fmt.Sprintf("%d個", n)   // 書式付きで文字列化
```
