### 分かったこと

**struct（次にちゃんとやるテーマ）**
- `type 名 struct { ... }`。フィールド大文字 = 外から見える、小文字 = パッケージ内だけ。
- 生成4種: `T{Field: v}`（推奨）/ `T{v1, v2}`（順番依存・脆い）/ `var x T`（ゼロ値）/ `&T{...}`（ポインタ）。
- メソッドは struct の外に `func (レシーバ) 名前()`。継承なし。
- 値レシーバ = コピー（書き換え不可）、ポインタレシーバ `*T` = 元を書き換え可。型内でどちらかに統一。
- コンストラクタは言語機能でなく慣習の `NewXxx()` 関数。
- 継承の代わり = 埋め込み（`type Dog struct { Animal; Breed string }`）。
- struct は代入で丸ごとコピー（値セマンティクス）。全フィールドが比較可能なら `==` で比較可。

**`go vet` の `string(int)` 警告**
- `string(1234)` は "1234" ではなく **コードポイント U+04D2 = 'Ӓ'**（1文字）。
- `go vet` に抑制コメントは無い。意図が明確な書き方に直すと消える:
  - 文字コードとして扱う → `string(rune(i))`
  - 数字の文字列が欲しい → `strconv.Itoa(i)` / `fmt.Sprintf("%d", i)`

**演算子（pra05 まとめ）**
- 算術: `/` は整数どうしだと切り捨て（`7/2 == 3`）。`%` は余り。`i == (i/j)*j + (i%j)`。
- ビット（2進で1桁ずつ）: `&`=両方1で1 / `|`=どちらか1で1 / `^`=違えば1 / `&^`=右が1の桁を左から消す。
  - 例: `3 &^ 6` → `011` から `110` の桁を消す → `001` = 1。
- シフト: `x << n` = ×2ⁿ、`x >> n` = ÷2ⁿ（切り捨て）。例 `5<<4=80`, `4>>2=1`。

**Go がビット演算子を持つ理由（設計思想）**
- Go の発明ではなく C からの相続。作者（グリーズマー / パイク / トンプソン）は Unix / Plan 9 の人。
- Go の「シンプル」= 機械を隠さない・驚かせない。英語らしく見せることではない。
  `x & mask` は隠れコストゼロなので Go 的にはむしろ理想的にシンプル。関数に包む方が複雑化。
- Go はシステム言語 → ネットワークのフラグ / ファイルフォーマット / 権限(0o755) / 暗号 /
  `iota` + `1<<n` では、ビットが「実装詳細」でなく「扱う対象そのもの」。
- 読みやすさを気にした証拠 = C に無い `&^`（ビットクリア）を Go が追加。
- 日常の Web / CLI コードにはまず出てこない。重要度は `+ - * / %` >>> `& | ^ << >>`。
- 詳細は `go-design-philosophy.md`。
